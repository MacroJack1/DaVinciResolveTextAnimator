# DaVinciResolveTextAnimator
A text animation plugin for DaVinci Resolve (This project is a work in progress, this is not a finished plugin but it's fully functional)

This is a text animation plugin with the option for letter by letter, word by word, or line by line animation. There is full control over timing and easing with options for fade, blur, rotation, scale, direction, and distance.

To install it just drag the .fuse file into your fuses folder.

This is the first public release so please test it and give me your honest feedback.
